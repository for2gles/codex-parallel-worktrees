# 하위칩 — Codex 앱 전용

이 스킬은 **Codex 앱의 공식 채팅·관리 Worktree 생성 경로만** 사용합니다.
CLI/App 두 모드를 선택하는 구조가 아니며, 앱 도구가 없으면 독립 CLI 방식으로 자동 우회하지 않습니다.
하위칩은 앱에 표시되는 별도 채팅이며 각각 별도 Git Worktree를 사용합니다.
제목은 상위칩이 `하위칩 · 로그인 API`처럼 짧은 작업명으로 지정하고, `You are 하위칩 ...` 역할 설명은 프롬프트에 둡니다.

## 상태: v0.5.0-app.5 미리보기

공식 앱 채팅 생성과 관리 Worktree 생성은 실제 확인했습니다. 완료 보고용 영구 FIFO 큐의 로컬 검사를 제공합니다.
**메인 자동 재개·작업 중 메시지 전달의 실제 모델 검증은 계정 사용량 제한으로 미완료**입니다.
같은 실행 중 앱 세션의 다른 터미널 접속도 아직 검증되지 않아 접속 명령을 생성하지 않습니다.
현재 미리보기는 기존 CLI판의 기능·호환성을 모두 충족한 완성본으로 배포하는 버전이 아닙니다.

앱 생성·메시지 도구를 사용할 수 있는 Codex 환경과 로컬 기록용 Node.js 18+·Git이 필요합니다.
Python·npm 패키지·개별 App Server·스킬 자체의 Worktree 생성기는 사용하지 않습니다.

## 소유 목록과 대상 선택

소유 관계는 **호스트 ID + 부모 세션 ID**로 구분합니다. 각 부모의 직접 하위칩 목록은 Git common dir의
`parallel-worktrees-app/owners/<owner-hash>.json`에 영구 보관하고, 정본은 `parallel-worktrees-app/state.json`입니다.
`owned` 명령이 자기 목록과 정확한 파일 경로를 반환합니다. 같은 이름이나 hi라는 메시지로 다른 세션의 칩을 선택하지 않습니다.
보관된 칩은 기본 목록에서 제외하고 전송 실패 뒤 자동으로 보관을 해제하지 않습니다.

## 메인의 작업 대기 금지

메인은 하위칩 작업 완료를 기다리는 wait/status/sleep 루프를 수행하지 않습니다.
대기가 필요하면 완료한 하위칩 또는 그 내부 알림 담당만 수행합니다.
내부 에이전트 2단계 테스트에서는 부모 응답 종료 뒤 알림 담당의 생존·메시지 전송을 확인했습니다.
별도 앱 하위칩의 종료 뒤 생존이나 메인 응답 종료 뒤 자동 재개까지 검증한 것은 아닙니다.

## 완료 보고 허가의 유지

사용자가 이미 요청한 완료 보고는 원문 사용자 메시지의 근거를 기록해 등록된 직접 부모에게만 전달합니다.
작업마다 같은 허가를 반복 요청하지 않습니다. 개인 report-policy는 원문 조회용 참조이며 권한을 부여하는 스위치가 아닙니다.
원문 확인 없이 부모가 허가를 만들어내거나 `허가가 없으니 큐에만 남겨라`라고 단정하지 않습니다.

## 사용

```text
$parallel-worktrees
이 저장소에서 별도 앱 채팅인 하위칩을 만들어줘. 각 칩은 앱 관리 Worktree를 사용해줘.
작업 완료 결과는 메인 채팅으로 보내 나에게 알려줘. 메인이 작업 중이면 완료 메시지를 큐에 보관해줘.
```

스킬은 사용자 요청과 앱 도구를 확인한 뒤 네이티브 생성 절차를 수행합니다.
완료한 칩이 큐를 기록하고, 부모가 바쁘면 앱 이벤트 대기를 하며, idle로 확인되면 네이티브 메시지를 전달합니다.
이는 살아 있는 칩의 모델 턴이 수행하는 절차이며, 모든 턴이 끝난 뒤 동작하는 별도 데몬이나 hook은 아닙니다.
도구의 입력 수락과 메인의 실제 사용자 보고는 구분합니다. 알림 자체로 추가 작업·회신·자동 병합을 요청하지 않습니다.
상세한 제약과 큐 처리 방법은 [앱 실행 절차](references/app-workflow.md), 검증 범위는 [VALIDATION.md](VALIDATION.md)를 보세요.

## 설치

Codex의 skill-installer로 `for2gles/codex-parallel-worktrees`의 루트 경로 `.`를
`parallel-worktrees`라는 이름으로 설치합니다. 현재 앱 전환 태그는 `v0.5.0-app.5`입니다.
기존 설치는 사용자 변경과 기존 실행을 확인해 보존한 뒤 교체하세요. 다음 턴부터 인식됩니다.

이전 독립 CLI 구현과 0.163–0.166 검증 기록은 **태그 `v0.4.1`과 그 이후의 기록 커밋**에 남아 있습니다.
그 결과가 현재 앱 모드의 검증을 대신하지는 않습니다. 기존 CLI 세션을 앱 세션으로 변환·이전하지 않습니다.

```bash
node --test tests/*.test.cjs
```
